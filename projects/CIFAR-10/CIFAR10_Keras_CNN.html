Datan esikäsittely¶

Kuvat ovat 32x32 pikseliä ja 3 kanavaa (RGB). Kuvat on normalisoitu skaalalla 0-1. Testi- ja validointidatan erottelu on tehty valmiiksi. Vastemuuttuja on muutettu one-hot-enkoodattuun muotoon käyttämällä keras.utils.to_categorical-funktiota. Tämä muuttaa alkuperäiset kokonaislukuarvot, jotka edustavat luokkia (0–9), binääriseksi vektoriksi.

Mallin rakennus¶

Mallissa käytetään konvoluutiokerroksia, jotka sisältävät ReLU-aktivaatioita, Batch Normalization -kerroksia ja MaxPooling-kerroksia, jotka vähentävät ulottuvuuksia. Dropout-kerroksia on lisätty estämään yliopetusta. Lopuksi, malli käyttää tiheää kerrosta ja softmax-aktivointia ennusteiden tekemiseen.

Alussa suodattimien määrä on pienempi, jotta malli voi oppia yksinkertaisia piirteitä. Syvemmillä kerroksilla suodattimien määrä kasvaa, jolloin malli pystyy tunnistamaan monimutkaisempia rakenteita. Kaksinkertaisia konvoluutiokerroksia käytetään, koska testauksessa se näytti parantavan mallin suorituskykyä. Tämä voi johtua siitä, että jos yhden konvoluutiokerroksen jälkeen suoritetaan MaxPooling, se voi johtaa piirteiden karkean muodon havaitsemiseen, mutta lisäämällä toisen konvoluutiokerroksen ennen MaxPoolingia, malli voi oppia tarkempia piirteitä ja välttää liiallista tiedon menetyksestä.

Käytimme lopussa kahta tiheää kerrosta, koska se näytti parantavan mallin kykyä yhdistää oppimiaan piirteitä paremmin.

inputs = keras.Input(shape=input_shape)

x = layers.Conv2D(32, kernel_size=(3, 3), activation='relu', padding='same')(inputs)
x = layers.BatchNormalization()(x)  
x = layers.Conv2D(32, kernel_size=(3, 3), activation='relu', padding='same')(x)
x = layers.BatchNormalization()(x)  

x = layers.MaxPooling2D(pool_size=(2, 2))(x)
x = layers.Dropout(0.25)(x)

x = layers.Conv2D(64, kernel_size=(3, 3), activation='relu', padding='same')(x)
x = layers.BatchNormalization()(x)  
x = layers.Conv2D(64, kernel_size=(3, 3), activation='relu', padding='same')(x)
x = layers.BatchNormalization()(x)  

x = layers.MaxPooling2D(pool_size=(2, 2))(x)
x = layers.Dropout(0.25)(x)

x = layers.Conv2D(128, kernel_size=(3, 3), activation='relu', padding='same')(x)
x = layers.BatchNormalization()(x)  
x = layers.Conv2D(128, kernel_size=(3, 3), activation='relu', padding='same')(x)
x = layers.BatchNormalization()(x)  

x = layers.MaxPooling2D(pool_size=(2, 2))(x)
x = layers.Dropout(0.25)(x)

x = layers.Flatten()(x)
x = layers.Dense(128, activation='relu')(x)
x = layers.Dropout(0.25)(x)
outputs = layers.Dense(num_classes, activation="softmax")(x)

model = keras.Model(inputs=inputs, outputs=outputs)

Kuvien tarkastelu¶

Suurimman osan kuvista malli osaa luokitella oikein hyvällä varmuudella, mutta on myös kuvia, joita malli ei osaa luokitella oikein. Tämä voi johtua kuvan laadusta ja kuvassa olevista objekteista. Osa näistä ei erotu yhtä selkeästi kuin toiset ja värimaailma saattaa olla hyvin samankaltainen. Esimerkkinä kolmas kuva, jonka malli on luokitellut linnuksi, mutta se on peura. Kuvassa näkyvät sarvet jäävät hyvin vahvasti taustan väriin ja malli ei välttämättä osaa erotella niitä.

Toinen esimerkki on kuudes kuva. Malli ei osaa hyvällä varmuudella sanoa onko kuvassa kissa vai koira. Kuvassa näkyy korvat, ja tumma eläimen pää, ilman sen selkeämpiä erottavia piirteitä, kuten kuonoa tai pään muotoa.

Johtopäätökset¶

FCN¶

Fully connected network suoriutui huonosti CIFAR-10 datasetillä, saavuttaen vain 50% tarkkuuden. Tämä johtuu siitä, että FCN ei pysty hyödyntämään kuvien spatiaalista rakennetta, joka on tärkeä osa kuvien luokittelua. Se johtaa siihen, että malli ei pysty oppimaan kuvien piirteitä tarpeeksi tehokkaasti. Tästä syystä testitappiokin oli korkea, noin 1.42. Parannettavaa on siis paljon. Voimme siis päätellä että FCN ei sovellu kovin hyvin kuvien luokitteluun.

CNN¶

Malli saavutti noin 80% testi tarkkuuden ja 0.60 kustannuksen. Tulokset osoittavat, että malli suoriutuu kohtuullisen hyvin kyseisellä datasetillä, luokitellen oikein 80% kuvista. Kustannus arvo antaa viitteitä siitä, että mallia voisi hieman peukaloida saadakseen vielä pienemmän testi kustannos arvon.

Kaiken kaikkiaan, konvulaatio tasojen, batch normalisaation, max poolin ja dropout:in käyttö yhdessä mahdollisti mallin tehokkaan oppimisen ja hyvän tarkkuus arvon, samalla kun se rajoitti ylioppimista.

CNN sopii cifar-10 datasetin käsittelyyn paremmin kuin FCN, koska se pystyy hyödyntämään kuvien spatiaalista rakennetta. CNN pystyy oppimaan kuvien piirteitä tehokkaammin, mikä johtaa parempaan suorituskykyyn ja tämä on suoraan nähtävissä mallin metriikoista.
